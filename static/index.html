⚖️ 减载配额试算 未试算

以当前架体为基准，只下调各层坯件重量（棚板/立柱/坐标/容量均不变），在每层减量不超过 现有坯件重量的条件下，求让全部有限容量立柱不再超载的最小总减载量。多层坯件载荷 会经现有整架分摊规则共同压到下层立柱，求解后按原规则重新整架校验。试算 不写入状态；确认后才把建议坯件重量写入架体并沿用自动保存， 一旦继续编辑架体，旧方案立即作废。

📐 层架抗倾覆试算 未试算

沿用当前编辑的架体：以各层累计高度作为该层棚板与坯件的重心高度、棚板中心 作为两者水平重心，按重量求整架重心；取底层非悬空立柱落点的凸包作为支撑多边形。 输入水平加速度 x/y 分量（单位 g），重心投影按「加速度 × 重心高度」平移后，计算投影点 到支撑边界的带符号最短距离：正=稳定、 0=临界、负=倾覆。 结果同步叠加在俯视图（支撑边界 + 重心/投影点）。试算只读不写盘； 落点不足以形成非零面积、或任一层无有效承托时明确返回无法评估；编辑架体后旧试算立即失效。

🚚 逐层装货顺序规划 未规划

以当前架体为准、保留全部棚板自重：先把所有层坯件重量置零，再把 坯件重量大于零的层（至多 12 层）按整层坯件一次加入模拟装货， 对每个已装子集用与抗倾覆试算相同的模型计算带符号裕量，并用动态规划找出 「全过程最小裕量最大」的加入顺序（同分按层序号字典序自下而上选取）。 输入水平加速度 x/y 分量（单位 g）。面板逐步列出新增层、累计坯件重量、裕量与 稳定判定；若最优顺序仍有非正裕量，会标明无法全程稳定。规划只读不写盘； 无有效承托、底层支撑凸包退化或初始棚板总重为零时无法规划，候选层超过 12 层会提示缩减范围； 编辑架体后旧结果立即作废。

🚪 连续窑门通行试算 未试算

按行进顺序录入每道窑门的开口横向中心、宽度、高度以及进入该门前本段最大横移量 （单位均为 mm），首门从横移 0 出发。后端由窑车台面与各层棚板求横向外廓、 累加层高求最高点；逐门给出可通过的横移闭区间（高度不足直接阻断）， 再按门序把上一可达区间按本段横移量扩张后与本门区间求交—— 首次交集为空即在该门阻断（即使各门单独能过）。全程可达时回溯一条满足各段横移限制的 位置序列，逐门列出左 / 右 / 顶部净空。试算只读取当前架体、不写盘； 架体或门参数改变后旧结果立即失效。

🛞 轮组承载试算 未试算

台面由矩形布置的四个车轮承托：填写台面内的左 / 右轮位 X 坐标与 前 / 后轮位 Y 坐标（mm）及四轮额定载荷（kg）。后端以底层非悬空立柱 的落点与实载为点载荷，按双向杠杆（双线性）比例把载荷分到四轮：落点越出轮组矩形时 允许外推，负反力不截零（否则力与力矩不平衡）。页面给出逐轮反力、利用率、超载与 负反力风险，并核对反力之和与绕 X/Y 轴力矩是否与点载荷一致。试算 只读不写盘；编辑架体后旧结果立即失效。
